# Portfólio Estudante — Emilian Monteiro da Soler

Projeto acadêmico desenvolvido para a Atividade Avaliativa N1 de Desenvolvimento de Aplicações I.

## Estrutura

- `index.html` — página semântica e formulários GET/POST.
- `styles.css` — estilos externos, mobile-first, Flexbox, Grid e Media Queries.
- `imagens/` — foto de perfil, banner e favicon.
- `evidencias/` — capturas e anotações de validação.

## Testes realizados

A página foi conferida nos breakpoints de 375px, 768px e 1200px, com atenção a sobreposição, legibilidade e rolagem horizontal. Os comentários do código documentam as decisões de semântica, formulários, cascata, box model, posicionamento e responsividade solicitadas no roteiro.
